# Turnaround Project Submission

## Project Name

Turnaround

## Technologies Used

React 19, TypeScript, Vite, Tailwind CSS, FastAPI, Python, PostgreSQL, Supabase, SQLAlchemy, Alembic, MapLibre GL, React Query, Firebase Cloud Messaging, Vercel, and Render.

## Project Description

Turnaround is an operational intelligence platform for commercial fleet and corridor logistics across East Africa. It helps fleet managers and dispatchers monitor vehicles, GPS positions, trips, containers, terminal dwell times, geofences, SLA breaches, operating costs, and demurrage risk from one centralized dashboard.

## Elevator Pitch

Turnaround transforms GPS fleet data into actionable logistics intelligence, helping carriers identify delays, reduce idle costs, improve turnaround times, and make faster dispatch decisions.

## Key Learnings

- Designed a multi-tenant logistics platform with role-based access control.
- Built real-time fleet tracking using GPS telemetry and MapLibre maps.
- Connected geofencing with dwell-time analysis and financial impact calculations.
- Modeled vehicle, driver, container, trip, and facility relationships.
- Improved operational workflows through category-aware asset and dispatch forms.
- Built dispatch workflows that distinguish powered vehicles from non-powered assets such as containers.

## Challenges Faced

- Designing one asset system that supports trucks, tankers, trailers, chassis, and containers without treating every asset like a vehicle.
- Keeping GPS data, vehicle assignments, trips, containers, and dwell events synchronized.
- Handling noisy GPS signals and preventing false geofence arrivals or departures.
- Building clear dispatch workflows with correct vehicle, driver, container, and location assignments.
- Creating useful financial insights from operational delays and excess dwell time.
- Making complex operational data easy to scan through live maps, dashboards, filters, and expandable asset details.
